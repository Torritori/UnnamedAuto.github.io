# Car Logo Explorer

Static GitHub Pages build for the logo explorer.

## Publish With GitHub Pages

1. Push this repository to GitHub.
2. Open `Settings` -> `Pages`.
3. Set source to `Deploy from a branch`.
4. Select branch `main` and folder `/docs`.
5. Save and wait for GitHub Pages to publish.

The site entry is `docs/index.html`.

## Notes

- The 23 local logo files used by the page are copied into `docs/assets/logos/`.
- Remote logo data is still loaded from `filippofilip95/car-logos-dataset`.
- If remote GitHub raw data fails, the page falls back to local logos.
